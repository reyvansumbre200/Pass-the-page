One-time setup

The site lives on GitHub, so this page needs a GitHub key to save changes. You only do this once per phone or laptop.

  1. Open github.com/settings/personal-access-tokens/new (logged in as reyvansumbre200).
  2. Name it Pass the Page. Set expiration to a date after the giveaway ends.
  3. Under Repository access, choose Only select repositories and pick Pass-the-page.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it below.
